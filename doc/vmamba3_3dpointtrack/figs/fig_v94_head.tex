\node[lbl] at (0,-8.2)
  {\textbf{Two ways to decide whether a point is visible, from exactly the same evidence.}
   Both paths see one pair of arrows per point per frame and nothing else --- no depth, no
   appearance, nothing from the depth refiner. The upper path is a hand-written rule: follow the
   point forward one frame and back again, and if it fails to land where it started, call it
   hidden. Two things about it matter. The distance it allows is a constant, the same for a point
   drifting slowly and one crossing the frame; and the answer is \emph{latched}, so a point called
   hidden once is hidden for every later frame. The lower path hands the same two arrows to a small
   network, which can learn a distance that depends on how fast the point is moving, and which
   judges each frame separately, so a point that disappears behind something can be called visible
   again when it reappears. The two outputs differ in kind: the rule emits one bit, visible or not;
   the network emits a probability, counted as visible above $0.5$. The re-appearance the sketch
   shows is not a corner case --- $63\%$, $52\%$ and $66\%$ of adt, drivetrack and pstudio points
   come back after being hidden, and the fixed rule recovers none of them.};
