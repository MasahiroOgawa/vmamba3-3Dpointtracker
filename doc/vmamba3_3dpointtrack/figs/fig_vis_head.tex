   is scored with the \emph{upper} path: the optical flow's forward--backward consistency mask,
   passed through unchanged. It is never learned. The \emph{lower} path is \texttt{vis\_head}, a
   two-layer MLP on the frozen trunk's per-point feature, added so the channel could be learned
   instead. Because everything but the head is frozen, one checkpoint serves both settings and
   the predicted 3-D positions are bit-identical between them, so the difference measured is the
   visibility channel alone. Note the dashed arrow: the flow mask is already the fourth channel
   of the trunk's per-point input, so the head does not lack that evidence --- it sees the mask
